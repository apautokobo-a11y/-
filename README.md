# 車両感覚トレーナー v1.0

お年寄りの方でも分かりやすい画面で、車の「前・左右・左前・後ろ」の感覚を、ぶつけずに練習できる 3D ドライブシミュレーションです。
標準の車種は **トヨタ プリウス(60系・日本仕様・右ハンドル)** です。

- プログラム: `car_sense_trainer_v1.0.py`(この 1 ファイルだけで動きます)
- 3D表示ライブラリ: `lib/three.module.min.js`(three.js r160・MIT License。同じフォルダに置くとネット無しでも動きます)

---

## 1. しくみ

Python のプログラムが小さな Web サーバーを起動し、3D の画面はブラウザ(WebGL)で描きます。
そのため **パソコンでもスマホ・タブレットでも同じ画面で操作できます**。スマホは同じ Wi-Fi につないで QR コードを読み取るだけです(アプリのインストールは不要)。

## 2. 必要なもの

- Python 3.8 以上(**追加のインストールは不要**。標準ライブラリだけで動きます)
- Chrome / Edge / Safari などの新しいブラウザ
- 初回だけインターネット接続(`lib/three.module.min.js` を同じフォルダに置いた場合は不要)

## 3. 起動のしかた

```
python car_sense_trainer_v1.0.py
```

1. 小さな操作画面が開き、ブラウザで練習画面が自動で開きます。
2. 終わるときは操作画面の「終了する」を押します。

オプション:

| オプション | 内容 |
|---|---|
| `--port 8765` | 使うポート番号(使用中なら自動で次の番号を使います) |
| `--no-browser` | 起動時にブラウザを開かない |
| `--no-gui` | 操作画面を出さずにコンソールで起動(アドレスと QR コードを文字で表示) |
| `--local-only` | スマホなど他の機器からの接続を禁止 |

## 4. スマホ・タブレットで使う

1. スマホを、アプリを起動したパソコンと **同じ Wi-Fi** につなぎます。
2. 操作画面(または練習画面の「📱 スマホ」ボタン)の QR コードをスマホのカメラで読み取ります。
3. 横向きにすると見やすくなります。縦向きにも対応しています。

つながらないとき:
- 初回に Windows の「ファイアウォールでブロックされています」画面が出たら **「アクセスを許可する」** を押してください(プライベートネットワークにチェック)。
- 操作画面の「スマホからの接続を許可する」がオンになっているか確認してください。

## 5. 練習の内容

| 練習 | 内容 | お題(判定) |
|---|---|---|
| ① 前の感覚 | 前の壁に近づく | 壁から 50cm 以内で止める(30cm 以内で ◎) |
| ② 左右の感覚 | 狭いポールの間を通り、左に寄せる | 停止枠で左の塀から 20〜40cm、まっすぐ止める |
| ③ 左前の感覚 | 角のポールに左前の角を近づけ、左折する | 左前の角をポールに 30cm 以内(15cm 以内で ◎)→ 左の道へ曲がる |
| ④ バック駐車 | 駐車スペースにバックで入れる | 白線の内側にまっすぐ(ずれ 6° 以内)、輪止めまで |

- 障害物までの距離を **数字(色つき)・ソナー表示・音** で知らせます(緑→黄→オレンジ→赤 の順に近い)。
- 真上からの画面には、距離の線、**運転席から見えない地面(紫)**、**ピラーで見えにくい方向(灰色)**、**予想進路(黄色)** を表示します。
- ぶつかると止まり、どこがどこに当たったかを表示します。

## 6. 操作方法

| 操作 | ボタン(マウス・タッチ) | キーボード |
|---|---|---|
| 前へ進む / 後ろへ下がる | ▲ / ▼(押している間だけ動く) | ↑ / ↓(W / S) |
| ハンドルを左 / 右へ | ◀ / ▶、または丸いハンドルをぐるっと回す | ← / →(A / D) |
| ハンドルをまっすぐ | まっすぐに戻す | C |
| 止まる | ■ 止まる | スペース |
| 練習をえらぶ | 上のタブ | 1〜4 |
| 見回す(運転席) | 左を見る / 前を見る / 右を見る / 後ろを見る、画面をドラッグ | Q / F / E / G |
| 視点を変える | 📷 視点を変える / ⇄ 入れ替え | V(大) / B(小) / X(入れ替え) |
| はじめの位置へ | ↺ やり直し | R |
| 音のあり・なし / 使い方 | 設定 / ？ | M / H |

## 7. 視点(カメラ)の種類

運転席から / 真上から(車が上) / 真上から(地図) / 斜め後ろから / 自由に動かす / バックカメラ(鏡写し・ガイド線つき) / フロントカメラ / 左サイドカメラ / 右サイドカメラ / 左ドアミラー / 右ドアミラー / ルームミラー の 12 種類。
運転席からの画面では、ドアミラーとルームミラーにも実際の景色が映り、バック時はセンターディスプレイにバックカメラが映ります。

## 8. ほかの車を追加する(車種エディタ)

1. 操作画面の「🚗 車種を追加・編集する」(または練習画面の「車種」→「＋ 車種を追加・編集する」)を開きます。
2. 「新しく作る」でテンプレート(プリウス / 軽自動車 / ミニバン / SUV の目安)を選びます。
3. カタログの「主要諸元」の数字(全長・全幅・全高・ホイールベース・トレッド・最小回転半径・タイヤサイズ など)を **mm のまま** 入力します。
4. 右側の図(外から・運転席から・真上からの死角)で確認し、「保存する」を押します。
5. 「この車で練習する」で、すぐにその車で練習できます。

- 保存先: `cars/<車種ID>.json`(.py / .exe と同じフォルダ)。「ファイルに書き出す / 読み込む」で他のパソコンへ移せます。
- 車種の保存・削除は、アプリを起動しているパソコンからだけ行えます(スマホからは不可)。
- 「目安で入力」「車体の形」の項目は、分からなければそのままで構いません(見た目と死角の計算に使います)。

## 9. exe にする(PyInstaller)

```
pip install pyinstaller
pyinstaller --onefile --noconsole --name car_sense_trainer_v1.0 --add-data "lib/three.module.min.js;lib" car_sense_trainer_v1.0.py
```

- `--add-data` を付けると three.js が exe に入り、ネット無しでも動きます(付けない場合は初回に自動ダウンロードして `lib/` に保存します)。
- 設定(`settings.json`)、車種(`cars/`)、エラー記録(`car_sense_trainer_error.log`)は **exe と同じフォルダ** に保存されます。
- `--noconsole` でも動くよう、画面への文字出力やサブプロセスは使っていません。

### ウイルス対策ソフトの誤検知について

- PyInstaller で作った exe は、ウイルス対策ソフトに誤って検知されることがあります。配布する前に [VirusTotal](https://www.virustotal.com/) で確認してください。
- Windows で「Windows によって PC が保護されました」(SmartScreen)と表示されたら、**「詳細情報」→「実行」** を押すと起動できます。

## 10. 保存されるファイル

| ファイル | 内容 |
|---|---|
| `settings.json` | ポート番号、スマホ接続の許可、起動時にブラウザを開くか |
| `cars/*.json` | 追加した車種 |
| `lib/three.module.min.js` | 3D表示ライブラリ(自動ダウンロード時) |
| `car_sense_trainer_error.log` | エラーが起きたときの記録 |

練習画面の設定(速さ・音・表示)は、ブラウザごと(パソコン・スマホごと)に保存されます。

## 11. ご注意

- プリウスの寸法は公表値(全長 4600 / 全幅 1780 / 全高 1430 / ホイールベース 2750 / トレッド 1560・1570 / 最小回転半径 5.4m / 195/50R19)を使っています。**前後オーバーハング・目の位置・車体の形・ミラーの位置は推定値** です。
- このソフトは練習用の目安です。実際の車の見え方・寸法とは異なる場合があります。実際の運転では必ず目で安全を確かめてください。
